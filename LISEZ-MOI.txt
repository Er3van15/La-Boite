LA BOITE - VERSION AVEC DEUX FICHIERS CSS

index.html : page accueil
spectacles.html : page spectacles
telephone.css : styles de base pour telephone
pc.css : adaptations tablette (650px) et PC (1000px)
images/ : ajoute tes images ici, sans changer les noms mentionnes dans les commentaires HTML.

Les deux fichiers CSS sont charges dans chaque page HTML, dans cet ordre : telephone.css puis pc.css.
Les regles dans pc.css ne s activent que sur les ecrans assez larges.

Pour tester : ouvre index.html puis reduis ou agrandis la fenetre du navigateur.
Les spectacles, tarifs et contacts sont des exemples de maquette.

Menu centre sur PC ; boutons Connexion et Inscription ajoutes. Les boutons de compte sont des liens de maquette sans formulaire.
